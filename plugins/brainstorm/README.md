# Brainstorm

Guided idea generation that produces structured, categorized lists of actionable ideas for any topic or challenge.

### Features

- Guided clarification to focus the brainstorm
- Auto-generates 3–5 themed categories relevant to your topic
- 3–5 specific, actionable ideas per category
- Clean structured list output
- Offers to dive deeper into any category or idea

### Skills

| Skill | Description |
|-------|-------------|
| `brainstorm` | Guided idea generation with structured output |

### Usage

```
brainstorm feature ideas for my product
```

```
help me think of names for our new onboarding flow
```

```
let's brainstorm ways to improve user retention
```
