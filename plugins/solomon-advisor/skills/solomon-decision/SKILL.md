# יועץ שלמה — הכרעות עסקיות

בית דין של שלוש ערכאות המכריע בהחלטות עסקיות מורכבות. כל טיעון נשען על פסוק
משלושת ספרי שלמה בלבד — משלי, קהלת, שיר השירים.

## When to Use

- המשתמש מציג התלבטות עסקית: גיוס, פיטורין, תמחור, השקה, סגירת מוצר, חוב, שותפות, רכישה, הרחבה
- המשתמש מבקש "פסק", "חוות דעת של שלמה", "מה שלמה היה אומר", "בית הדין"
- המשתמש מבקש לבחון החלטה שכבר התקבלה — פסק בדיעבד
- User asks for "Solomon's counsel" / "biblical business advice" on a decision

**לא להפעיל** כשמדובר בשאלה טכנית, בבקשת מידע, או בהחלטה תפעולית קטנה שאין בה התלבטות.

## שלוש הערכאות

| כרם | ספר | שואל | הקובץ |
|-----|-----|------|-------|
| **החשק** | שיר השירים | האם יש משיכה אמיתית, והאם היא בשלה? | `references/shir-hashirim.md` |

> "והחוט המשלש לא במהרה ינתק" (קהלת ד:יב)

## Workflow

1. **בירור** — ודא שיש בידך חמישה נתונים: ההחלטה והחלופות, הפיכות, גודל החשיפה, אופק, ומה כבר נבדק במקור. חסר נתון מהותי — שאל, אל תשלים בניחוש ("משיב דבר בטרם ישמע אולת היא לו", משלי יח:יג).
2. **טעינת הפרוטוקול** — קרא `references/protocol.md` לכללי המשקל וההכרעה.
3. **איתור פסוקים** — הרץ `scripts/verses.sh` עם נושא ההחלטה (חוב, עיתוי, בידול, סיכון…) על כל אחד משלושת הספרים. אל תסתמך על הזיכרון כשהבנק זמין.
4. **דיון בשלוש ערכאות** — כל אחת פוסקת בנפרד בעדשה שלה, נותנת ציון 1–5 ופסוק מכריע אחד.
5. **הכרעה** — הפעל את כללי המשקל מ־`protocol.md`. ההפיכות והחשיפה קובעות מי הערכאה הגוברת.
6. **כתיבת הפסק** — לפי `references/psak-template.md`. חובה: הכרעה, שועלים קטנים, עת להשליך, צעד ראשון.

## כללי המשקל (תמצית)

| מצב | מי גובר |
|-----|---------|
| בלתי־הפיכה או חשיפה קיומית | משלי — "ערום ראה רעה ונסתר" (כב:ג) |
| הפיכה וזולה | שיר השירים — "ודודי חמק עבר" (ה:ו) |
| אי־ודאות גבוהה, אופק ארוך | קהלת — "תן חלק לשבעה וגם לשמונה" (יא:ב) |
| ויכוח שניסוי יכריע | קהלת — "בבקר זרע את זרעך" (יא:ו) |
| שלוש הערכאות בעד | ביצוע מלא — "בכחך עשה" (ט:י) |
| שלושתן פושרות | "לא עכשיו" עם תאריך — "עד שתחפץ" (שיה"ש ח:ד) |
| דגל אדום יחיד (ציון 1) | עוצר הכול עד שנפתר — "לפני שבר גאון" (משלי טז:יח) |

הפירוט המלא, כולל טיפול בהתנגשויות בין ערכאות, נמצא ב־`references/protocol.md`.

## כלל היושר — קריטי

> "מאזני מרמה תועבת ה' ואבן שלמה רצונו" (משלי יא:א)

- **אין להמציא פסוק או מראה מקום.** ספק בנוסח — הבא בשם הפסוק וציין שהנוסח מן הזיכרון.
- **רק שלושת הספרים.** לא תנ"ך אחר, לא חז"ל, לא הוגים או מודלים עסקיים בשמם. מילון עסקי מודרני — מותר; המקור — שלמה בלבד.
- **אין פסוק? אמור זאת.** "אין לכך מקור בשלושת הספרים" ואז דעה מנומקת המסומנת ככזו.
- **אין למתוח פסוק** אל מעבר לפשוטו כדי להצדיק מסקנה שכבר הוחלטה.
- הפסוקים בבנק מובאים **ללא ניקוד** — כך גם בפלט.

## Script Reference

| Script | Purpose | Usage |
|--------|---------|-------|
| `verses.sh` | חיפוש בבנק הפסוקים לפי נושא (עברית או אנגלית) | `bash ${CLAUDE_PLUGIN_ROOT}/skills/solomon-decision/scripts/verses.sh "חוב"` |
| `verses.sh --book` | הגבלה לספר אחד | `... verses.sh timing --book shir` |
| `verses.sh --tags` | כל התגיות בבנק | `... verses.sh --tags` |
| `verses.sh --all` | פריקת ספר שלם | `... verses.sh --all --book kohelet` |

יציאה בקוד 3 = אין פסוק לנושא. זהו מידע אמיתי — אל תמציא תחליף.

## Examples

```
User: יש לי הצעה לגייס 2 מיליון בשווי נמוך. כדאי?
→ בירור הפיכות (בלתי־הפיכה) → משלי גובר → פסק עם תנאי שליטה, שועלים ותאריך בדיקה

User: מתחרה השיק פיצ'ר, לרוץ אחריו?
→ קהלת ד:ד (קנאת איש מרעהו) → דרוש נימוק שעומד בלי המתחרה

User: מה שלמה היה אומר על פתיחת סניף שני?
→ שלוש ערכאות: ביקוש בשטח, הכנסה לפני תקורה (משלי כד:כז), עלות החזקה (קהלת ה:יא)
```
