# solomon-advisor

סוכן שמכריע בהחלטות עסקיות מורכבות, ומקור הסמכות שלו הוא שלושת ספרי שלמה בלבד:
**משלי, קהלת ושיר השירים**.

> "והחוט המשלש לא במהרה ינתק" (קהלת ד:יב)

A business decision agent whose entire reasoning corpus is King Solomon's three books.
It deliberates as a panel of three courts and returns a ruling — not a summary.

---

## הרעיון

רוב יועצי ההחלטות מחזירים סקירת שיקולים. הסוכן הזה פוסק.

שלושת הספרים אינם קישוט — כל אחד מהם הוא עדשה שונה על אותה החלטה, והמתח ביניהם
הוא מנוע ההכרעה:

| כרם | ספר | שואל | דגל אדום |
|-----|-----|------|----------|
| **החשק** | שיר השירים | האם יש משיכה אמיתית, והאם היא בשלה? | אין ראיה לביקוש — רק אהבה שלנו לרעיון |
| **הזהירות** | משלי | האם זה נבון, ומה מחיר הטעות? | קיים תרחיש שבו החברה לא שורדת |
| **התוחלת** | קהלת | האם זה יחזיק מול הזמן והמקרה? | אין תנאי עצירה ואין מדד שיגלה טעות בזמן |

שיר השירים הוא הספר היחיד מהשלושה שמדבר על רצון וכמיהה — ולכן הוא הערכאה של
ביקוש, בידול ועיתוי. משלי הוא ספר הסיבתיות: מעשה ותוצאה, סיכון וחוב. קהלת הוא
ספר אי־הידיעה: הבל, מקרה, זמן ופיזור.

## Features

- **בית דין של שלוש ערכאות** — כל אחת פוסקת בנפרד עם ציון 1–5 ופסוק מכריע
- **כללי משקל מפורשים** — ההפיכות וגודל החשיפה קובעים מי גובר, לא התחושה
- **בנק של 241 פסוקים** מתויגים, כל אחד עם תרגום עסקי ושאלת בדיקה
- **פלט מובנה** — הכרעה, שועלים קטנים, תנאי עצירה, צעד ראשון
- **חיפוש פסוקים בעברית ובאנגלית** דרך סקריפט bash ללא תלויות
- **כלל יושר קשיח** — אין המצאת פסוקים, אין מקורות זרים, אין מתיחת פסוק למסקנה

## התקנה

```bash
claude plugins add oneqmethod/skills
claude plugins install solomon-advisor
```

אין תלויות — הסקריפט הוא bash + awk בלבד.

```

מה שלמה היה אומר על פיטורי שליש מהצוות?
תן לי פסק על הרכישה הזאת
```

```
Use the solomon agent to rule on whether we should take the acquisition offer
```

### בנק הפסוקים

כל רשומה בבנק:

```
### משלי כב:ז
עשיר ברשים ימשול ועבד לוה לאיש מלוה
tags: חוב, מימון, debt, leverage, loan, financing, terms
עסקית: כל חוב הוא העברת שליטה. הריבית היא המחיר הגלוי; התנאים הם המחיר האמיתי.
בדיקה: מי מחזיק בהחלטות שלנו אחרי שנחתום — ובאילו תנאים?
```

### הסקריפט

```bash
verses.sh "חוב"                    # חיפוש בשלושת הספרים
verses.sh timing --book shir       # הגבלה לספר אחד (mishlei|kohelet|shir)
verses.sh --tags                   # כל התגיות
verses.sh --all --book kohelet     # ספר שלם
verses.sh --count                  # מספר הפסוקים בבנק
```

קוד יציאה 3 = אין פסוק לנושא. זהו מידע אמיתי, והסוכן מנחה לומר זאת ולא להמציא תחליף.

## הערות על המקורות

- הפסוקים מובאים **ללא ניקוד**, בכתיב המסורה, כדי למנוע שגיאות ניקוד בטקסט מקודש.
- הפרשנות בשדה "עסקית" היא **קריאה יישומית מודרנית** לצורכי החלטה עסקית, ואינה
  מתיימרת להיות פרשנות מסורתית של הכתוב.
- שיר השירים נקרא כאן בפשוטו — כשירת חשק וכרמים — משום שדימויי הכרם, השמירה
  והעונות הם שנושאים את ההיגיון העסקי. הקריאה האלגורית המסורתית אינה נדונה כאן.
- הסוכן מונחה שלא להמציא פסוק או מראה מקום, ולומר במפורש כשאין מקור לנושא.
