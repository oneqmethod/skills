# Frontend Design

Frontend design assistant for creating polished UI components, layouts, and design systems with modern CSS and accessibility best practices.

## Features

- Generate UI components (buttons, cards, forms, modals, navigation, etc.)
- Create color palettes and design token systems
- Build responsive layouts with flexbox and CSS grid
- Apply WCAG accessibility standards (contrast, ARIA, keyboard nav)
- Support for HTML/CSS, React + Tailwind, and CSS custom properties
- Micro-interactions and motion with `prefers-reduced-motion` support

## Design Principles

- **8pt spacing grid** - consistent spacing scale
- **WCAG AA accessibility** - 4.5:1 contrast for text, keyboard navigation, ARIA
- **Mobile-first responsive** - breakpoints from small to large
- **Performance-aware** - `transform`/`opacity` animations, system font stacks
- **All interactive states** - default, hover, focus, active, disabled
