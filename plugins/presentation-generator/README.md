# Presentation Generator

Generate beautiful dark-themed HTML presentations from any document.

## Features

- Auto-detect document type (PRD, transcript, notes, articles)
- Auto-detect language for RTL/LTR support
- Dynamic theme colors based on content topic
- Keyboard navigation (arrow keys)
- Chapter sidebar navigation
- Print-friendly CSS for PDF export

## Usage

Invoke the skill with your document content:

```
Create a presentation from this PRD: [content]
```

Optional theme override:

```
Create a presentation with the "tech" theme from: [content]
```

## Theme Colors

| Topic | Color |
|-------|-------|
| Tech/Dev | Cyan |
| Business/Sales | Green |
| Finance | Gold |
| Health/Medical | Teal |
| Education | Purple |
| Creative/Design | Pink |
| Default | Blue |
